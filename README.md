# demo-cphaco2

Bản demo website Hoa Viên Bình Dương (Công ty CP Đầu tư Xây dựng Chánh Phú Hòa). HTML, CSS và JS tĩnh, không cần cài đặt.

- Trang chủ: `trang-chu.html`
- Xem thử trên máy: `python -m http.server 5520` rồi mở http://localhost:5520/trang-chu.html
- Trang con được ghép từ `_src/` bằng `python _src/build.py` (đầu trang, khung đặt lịch và chân trang lấy từ `trang-chu.html`).
